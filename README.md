# LLMrequest

A collection of scripts and tools for making requests to various Large Language Model (LLM) APIs, with a focus on Thai language models and medication error classification tasks.

## Project Structure:  Python Scripts

## Usage

1. Configure your API keys in `config.py` or `.env` file
2. Run any Python script to interact with the respective LLM provider
3. For web interface: run `server.ps1` and open http://localhost:5000 in your browser
4. For local models: ensure Ollama is running and update model name in `ollama.py`

Code will read content in column 'รายละเอียด' and send a query request to server
then will collect result and export result as  `<model_provider>_<timestamp>.csv ` file automatically 
### Typhoon (as tester)
Run:  `python typhoon_requests.py `

### Ollama (Qwen, Llama, Mistral)
Run:  `python ollama.py `
- adjust model name and URL endpoint first

### ChatGPT
Run:  `python chatgpt.py `

### Claude
Run:  `python claude.py `

### Gemini
Run:  `python gemini.py `

## Description (Generated by AI)

- **`chatgpt.py`** - OpenAI GPT API client with streaming support. Demonstrates how to make requests to OpenAI's GPT models (e.g., gpt-5.6) with streaming response handling.

- **`claude.py`** - Anthropic Claude API client with streaming support. Shows how to interact with Claude models (e.g., claude-3-5-sonnet-latest) using the Anthropic SDK for text generation.

- **`gemini.py`** - Google Gemini API client for medication error classification. Uses Google's generative AI to classify medication error reports into 5 categories (Prescribing, Transcribing, Predispensing, Dispensing, Administration Errors) with streaming responses.

- **`ollama.py`** - Local Ollama API client for running models locally. Connects to locally-hosted Ollama instances (default: http://localhost:11434) to run open-source models like qwen3:0.6b for medication error classification.

- **`openrouter.py`** - OpenRouter API client for accessing multiple LLM providers. Provides a unified interface to access various models through OpenRouter's aggregation platform with user input for model selection.

- **`thaiLLM.py`** - Thai LLM API client for Thai language models. Connects to thaillm.or.th API to access Thai-specific language models (thalle-0.2-thaillm-8b-fa) with streaming support and interactive chat interface.

- **`typhoon.py`** - OpenTyphoon API client using OpenAI SDK. Interacts with SCB 10X's Typhoon models (typhoon-v2.5-30b-a3b-instruct) using the OpenAI-compatible API with streaming responses and interactive chat.

- **`typhoon_requests.py`** - OpenTyphoon API client using requests library. Alternative implementation for Typhoon API using direct HTTP requests with pandas integration for batch processing medication error data from CSV files.

- **`typhoon_mdfile.py`** - OpenTyphoon API client with file context. Uses requests library to send queries to Typhoon API with additional context from markdown files (e.g., alteplase.md) for RAG-style question answering.

### PowerShell Scripts

- **`server.ps1`** - Local HTTP server for Typhoon API proxy. Creates a simple HTTP server on port 5000 that serves the HTML interface and proxies API requests to OpenTyphoon, handling CORS and authentication.

- **`test.ps1`** - OpenTyphoon API test script. Simple PowerShell script to test connectivity and responses from the OpenTyphoon API with basic chat completion requests.

### HTML Files

- **`locallm.html`** - Web-based chat interface. Provides a modern, responsive chat UI that connects to the local server (server.ps1) for interacting with Typhoon models through a browser interface.

- **`error.html`** - Error page template. Cloudflare-style error page displayed when the Thai LLM API returns a 502 Bad Gateway error, showing connection status and troubleshooting information.

### Data Files

- **`Raw-50.csv`** - Raw medication error reports dataset. Contains 50 medication incident reports with columns: report code, severity, summary, and detailed description in Thai language.

- **`typhoon_260804_220506.csv`** - Typhoon classification results. Output file containing Typhoon model's classification of medication errors with report codes, details, and predicted error categories with rationales.

## Features

- **Multiple LLM Providers**: Support for OpenAI, Anthropic, Google Gemini, Ollama (local), OpenRouter, Thai LLM, and OpenTyphoon
- **Streaming Responses**: All implementations support streaming API responses for real-time output
- **Medication Error Classification**: Specialized prompts for classifying medication errors into 5 standard categories
- **Thai Language Support**: Optimized for Thai language processing and medication terminology
- **Local Deployment**: Options for running models locally via Ollama or self-hosted server
- **Web Interface**: Browser-based chat UI for easy interaction
- **Batch Processing**: Scripts for processing multiple medication error reports from CSV files
